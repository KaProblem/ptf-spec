# Introduction

A one-step course: by the end the learner can count from one to ten.

# Prior knowledge

Most learners above primary-school age can count to ten; ask one question
across a decade boundary (`q3`) and skip the step when they answer it.

# Tutor notes

Keep it playful; the learner is a child.
