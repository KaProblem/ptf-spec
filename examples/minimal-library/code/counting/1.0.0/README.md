# Counting lab

Two tiny Python programs that count. They need only Python 3.8 or newer.

| Step | Run |
| --- | --- |
| 1. Count to ten | `python steps/01_count.py` |
| 2. Count to any number | `python steps/02_count_to.py --to 20 --by 2` |

## Build on it

- Count backwards from 10 to 1.
- Count only the odd numbers.
